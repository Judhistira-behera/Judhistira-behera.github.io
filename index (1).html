Automation projects

Class recordings that save themselves

After class: Meet recordings go to the right batch folder.

Problem

Students kept asking for recordings. Meet saves them in the host’s Drive, so someone had to find, move and share each one by hand.

What I built

A script that checks Gmail every 15 minutes, matches each “Meeting records” email to its batch, and saves only the video into that batch’s folder. Each folder has one view link for students.

  • Skips transcripts and attendance sheets.
  • Moves the file, or copies it when another trainer owns it.
  • Labels each email Saved or NeedsReview, so nothing repeats or gets lost.

Result

Students get recordings within minutes, and the ops team no longer handles requests.

View code 
const MAPPINGS = [
  { keyword: "Batch A 7AM", folderName: "Batch A Recordings" },
  { keyword: "Batch B 8PM", folderName: "Batch B Recordings" }
];

function saveRecordings() {
  const saved = getOrCreateLabel("Recording-Saved");
  const review = getOrCreateLabel("Recording-NeedsReview");

  MAPPINGS.forEach(m => {
    const folder = getOrCreateFolder(m.folderName);
    const threads = GmailApp.search(
      `"${m.keyword}" -label:Recording-Saved -label:Recording-NeedsReview`, 0, 50);

    threads.forEach(thread => {
      let found = false;
      thread.getMessages().forEach(msg => {
        Object.keys(extractDriveFileIds(msg.getBody())).forEach(id => {
          const file = DriveApp.getFileById(id);
          if (file.getMimeType().indexOf("video") !== 0) return; // video only
          try { file.moveTo(folder); }                            // if we own it
          catch (e) { file.makeCopy(file.getName(), folder); }    // otherwise copy
          found = true;
        });
      });
      thread.addLabel(found ? saved : review);
    });
  });
}
// helpers: getOrCreateLabel, getOrCreateFolder, extractDriveFileIds (regex)
// trigger: runs every 15 minutes

One-click student onboarding emails

Before class: branded welcome emails from a Google Sheet.

Problem

Each new student needed an email with trainer, timing, start date and class links. Writing them by hand was slow, uneven and easy to send twice.

What I built

A custom menu in Google Sheets. The team fills the Class Data sheet and clicks Send Onboarding Emails. Each student gets a HTML email with a schedule table, a Join Class button and a group link.

  • Rows marked Sent are skipped, so no one is emailed twice.
  • A timestamp is saved for every email.
  • A plain-text version is included for email apps that cannot show HTML.

Result

Every student gets the same professional welcome, sent in one click by anyone on the team.

View code 
function sendOnboardingEmails() {
  const sheet = SpreadsheetApp.getActive().getSheetByName("Class Data");
  const data = sheet.getDataRange().getValues();
  const headers = data[1];
  const statusCol = headers.indexOf("Status") + 1;
  const timeCol = headers.indexOf("Sent Timestamp") + 1;

  for (let i = 2; i < data.length; i++) {
    const rec = {};
    headers.forEach((h, c) => rec[h] = data[i][c]);
    if (!rec["Student Email"] || rec["Status"] === "Sent") continue; // no duplicates

    const options = {
      to: rec["Student Email"],
      subject: `Welcome: your onboarding details (${rec["Student Name"]})`,
      body: buildPlainBody(rec),
      htmlBody: buildHtmlBody(rec)
    };
    if (rec["CC Email"]) options.cc = rec["CC Email"];
    MailApp.sendEmail(options);

    sheet.getRange(i + 1, statusCol).setValue("Sent");
    sheet.getRange(i + 1, timeCol).setValue(new Date());
  }
}
// buildHtmlBody / buildPlainBody create the email from the row

Trainer leave alerts

During delivery: the team knows about leave the moment it is filed.

Problem

Leave news travelled by scattered messages or daily sheet checks, so batch owners found out late.

What I built

A Google Form wired to a script. When a trainer submits it, the pod leads and ops team get an email with the name, dates, timings and reason. Replies go straight to the trainer.

Result

Daily manual sheet checks are gone, and replacements can be planned early.

View code 
const CONFIG = {
  FIELDS: { email: "Email address", startDate: "Leave Start Date",
            endDate: "Leave End Date", startTime: "Start Time",
            endTime: "End Time", reason: "Reason" },
  NOTIFY: ["pod.lead@company.com", "ops.team@company.com"]
};

function onFormSubmit(e) {
  const get = f => (e.namedValues[f] && e.namedValues[f][0]) || "N/A";
  const email = get(CONFIG.FIELDS.email);
  const first = email.split("@")[0].split(".")[0];
  const name = first.charAt(0).toUpperCase() + first.slice(1);

  const body =
    `Hi Team,\n\nA trainer has submitted a leave request:\n\n` +
    `Name: ${name}\nSubmitted by: ${email}\n` +
    `Leave Start: ${get(CONFIG.FIELDS.startDate)} (${get(CONFIG.FIELDS.startTime)})\n` +
    `Leave End: ${get(CONFIG.FIELDS.endDate)} (${get(CONFIG.FIELDS.endTime)})\n` +
    `Reason: ${get(CONFIG.FIELDS.reason)}`;

  MailApp.sendEmail({
    to: CONFIG.NOTIFY.join(","),
    subject: `Leave form filled by ${name}`,
    body: body,
    replyTo: email
  });
}
